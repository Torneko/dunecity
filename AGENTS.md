# Dune Legacy Tornie

Independent RTS based on corrected DuneCity Tornie 1.0.524-26 (80799faba1b66c64887286446f5ed6b0df985226).

Preserve deterministic gameplay, stable item IDs, save compatibility gates, bundled mod resources and original attribution. City simulation is removed.

Read README.md and relevant source before edits. Use scripts/bump-version.sh for the three canonical version fields. Build dunelegacy and dunelegacy_tests, and run CTest for engine changes.

Update the French and English documentation website with every game update: version, affected unit/building pages, technology levels and prerequisites, factions, achievements, PNG assets and downloads. Keep the local/offline package and the published GitHub Pages site aligned with each released game version. This is Tornie's standing request and applies on both PCs. Follow docs/WEBSITE.md; recover the current site from origin/gh-pages or the latest release asset before editing, rather than regenerating from an older local copy.
