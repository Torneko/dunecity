# Dune Legacy Tornie

Independent RTS based on corrected DuneCity Tornie 1.0.524-26 (80799faba1b66c64887286446f5ed6b0df985226).

Preserve deterministic gameplay, stable item IDs, save compatibility gates, bundled mod resources and original attribution. City simulation is removed.

Read README.md and relevant source before edits. Use scripts/bump-version.sh for the three canonical version fields. Build dunelegacy and dunelegacy_tests, and run CTest for engine changes.
