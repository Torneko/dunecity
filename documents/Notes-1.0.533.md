# Dune Legacy Tornie 1.0.533

Les contrôles automatisés précédents sont détaillés dans le rapport fourni. La dernière correction de la bannière Fremen a été compilée ; les tests complets n’ont pas été relancés, à la demande de Tornie.

## Campagne Kleshmersh en Vanilla

Les 22 scénarios reprennent la véritable campagne Harkonnen de Dune II : joueur Harkonnen → Kleshmersh, Atreides → Harkonnen, Ordos → Sardaukar et Sardaukar → Mercenary. Le terrain, les positions, les équipes, les renforts, les crédits et les objectifs restent ceux des missions originales.

Dans cette campagne, les Harkonnen sont vert foncé, les Sardaukar fuchsia et les Mercenary turquoise. Les Mercenary gardent leurs technologies Vanilla. Les palais ennemis choisissent au hasard un pouvoir classique à chaque recharge : missile, Fremen ou saboteur. Le saboteur utilise le comportement habituel Ordos/Mercenary.

## Escouades supplémentaires dans Tornie, Tornie Lite et Jericho

- **5 soldats** : Caserne, niveau de partie 4, deuxième amélioration, sans IX. Nouvelle commande en tête, aux côtés de celle de trois.
- **5 troopers** : Worfinery uniquement, niveau de partie 7, amélioration et IX. Nouvelle commande en tête, aux côtés de celle de trois.
- **Prix** : trois fois le prix de l’unité seule selon la maison d’origine du bâtiment, y compris après capture.
- **Éditeur** : les escouades sont les premiers ajouts de la section custom, soldats puis troopers. Leurs tuiles reprennent les escouades Infantry/Troopers avec l’étoile bleue. Un placement donne cinq unités en jeu ; les cartes et renforts conservent ce groupe.

Les conditions concernent toutes les maisons lorsqu’elles possèdent le bâtiment. La chaîne habituelle de construction reste indiquée dans les fiches : une maison qui ne peut pas construire une Caserne peut utiliser une Caserne fournie ou capturée.

## Trois nouveaux hauts faits

- **Barrage de missiles** : lancer trois missiles de palais ou plus dans une même partie.
- **Récolte bleue** : collecter de l’épice bleue avec une moissonneuse.
- **Récolte mauve** : collecter de l’épice mauve avec une moissonneuse.

Le catalogue comporte 46 hauts faits. Le compteur des missiles reprend après une sauvegarde.

## Utilisation locale

Extraire le ZIP du jeu et lancer dunelegacy.exe. Démarrer une nouvelle partie pour bénéficier des nouvelles commandes ; les anciennes sauvegardes gardent leurs règles enregistrées. Les sauvegardes 1.0.533 demandent cette version du jeu.

Le site français et anglais contient les nouvelles conditions et les prix par maison, ainsi que les 106 PNG, dont les images Vanilla ajoutées. Site : https://torneko.github.io/dunelegacy-tornie/ — Jeu : https://github.com/Torneko/dunelegacy-tornie/releases/tag/v1.0.533

La liste des unités de l’éditeur défile avec la molette et une barre verticale quand la hauteur disponible ne suffit pas, pour garder les dernières unités accessibles.

Le mode **Sabotage** de l’éditeur fonctionne comme une chasse aux bâtiments ennemis à capturer pour les soldats et les troopers, y compris les escouades. En jeu, le bouton **Sabotage** se trouve sous **Retraite** ; une sélection mixte transmet cet ordre à l’infanterie seulement. Les bâtiments alliés ou non capturables sont ignorés, et une cible disparue est remplacée. La capture conserve les règles habituelles : un bâtiment dans le rouge change de propriétaire, sinon l’infanterie lui inflige des dégâts et est consommée.

La bannière Fremen est rétablie dans la confirmation du choix de maison. Son image originale est conservée ; le fond de la planète utilise désormais un format compatible avec cette bannière.
